# Fundamentos de Desarrollo Web para Principiantes

Bienvenido al repositorio del curso **Fundamentos de Desarrollo Web para Principiantes**!

En este curso ,dirigido a estudiantes de entre **12 y 17 años**, aprenderás los conceptos básicos de desarrollo web utilizando **HTML y CSS**, creando páginas web sencillas directamente desde el navegador, sin necesidad de instalar software adicional.

## Ubicación de las Lecciones

Cada módulo está compuesto por dos lecciones. Los archivos de cada lección pueden encontrarse en las carpetas `/starter-files` y `/completed-examples`.

| Módulo | Lecciones | Carpeta |
|---------|------------|----------|
| 🟢 Módulo 1: Conociendo la Web y HTML Básico | Lección 1 y Lección 2 | `module-1` |
| 🟡 Módulo 2: Imágenes, listas y enlaces | Lección 3 y Lección 4 | `module-2` |
| 🟠 Módulo 3: Hola CSS, dale color a tu vida | Lección 5 y Lección 6 | `module-3` |
| 🔵 Módulo 4: Ajustando los detalles | Lección 7 y Lección 8 | `module-4` |
| 🟣 Módulo 5: Proyecto Final y Consejos | Lección 9 y Lección 10 | `module-5` |


## Estructura del Repositorio

### `/starter-files`

Contiene los archivos iniciales utilizados al comienzo de cada lección. Cada carpeta contiene un archivo index.html y/o stylesheet.css que pueden usar como punto de partida para desarrollar los ejercicios.

```text
starter-files/
├── module-1/
├── module-2/
├── module-3/
├── module-4/
└── module-5/
```

### `/completed-examples`

Contiene los archivos archivo index.html y/o stylesheet.css de las soluciones completas de los ejercicios mostrados durante las clases y videos del curso.

```text
completed-examples/
├── module-1/
├── module-2/
├── module-3/
├── module-4/
└── module-5/
```

### `/scripts`

Contiene material de apoyo para la elaboración del curso, incluyendo guiones, borradores y notas de grabación.

```text
scripts/
├── guion-sebasthian.md
├── guion-victor.md
├── guion-alexandra.md
├── guion-luis.md
└── guion-david.md
```

## Cómo Utilizar este Repositorio

1. Ingresa a la carpeta correspondiente a la lección que deseas estudiar.
2. Abre los archivos dentro de `/starter-files`.
3. Sigue las instrucciones del video o la clase.
4. Completa el ejercicio.
5. Compara tu solución con los archivos ubicados en `/completed-examples`.
